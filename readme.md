## 📋 Sobre o Projeto

Sistema completo para gestão de tarefas e cadastro de produtores rurais. Desenvolvido para facilitar o dia a dia no campo, permitindo organizar atividades e manter um registro atualizado dos produtores e suas declarações.

### 🎯 Funcionalidades

#### 📝 Módulo de Tarefas
- ✅ Adicionar, editar e remover tarefas
- 🎯 Definir prioridades (Alta/Média/Baixa)
- 🔍 Filtrar por prioridade e status
- ✅ Marcar tarefas como concluídas
- 💾 Persistência de dados com LocalStorage
- ✏️ Edição inline sem prompts

#### 🌾 Módulo de Produtores Rurais
- 👤 Cadastro completo (Nome, CNPJ, Propriedade)
- 📄 Controle de declarações com checkbox
- 🔍 Busca por nome, propriedade ou CNPJ
- 📋 Ordenação alfabética A-Z
- 📊 Estatísticas em tempo real
- 💾 Salvamento automático no navegador
